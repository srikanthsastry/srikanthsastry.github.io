**Using the model as observer that describes deviations rather than judge that declares conformance.**

After forward-pass convergence, run a reverse pass asking the model to describe deviations with receipts (spec says X, code does Y). Observer framing mitigates [suggestible-actor-properties](/garden/suggestible-actor-properties/) bias toward satisfying the goal; receipt is the value, not yes or no. This surfaces [directive-gap-hidden-by-confabulation](/garden/directive-gap-hidden-by-confabulation/) on M1→M2, complements [co-artifact-model](/garden/co-artifact-model/), and applies [confabulation-is-plausible](/garden/confabulation-is-plausible/) to evaluation itself. Observation confabulates too, so false positives grow with models and modules.
