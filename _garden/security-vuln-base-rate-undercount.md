**The reported 25-30% AI security vulnerability rate is an undercount. Six industry static analysis tools combined miss 97.8% of formally provable vulnerabilities.** Blain & Noiseux (2026) tested static analysis tools against Z3-provable vulnerabilities and found that the tools used to detect the Fu et al. base rate have massive blind spots. The 25-30% figure represents what the detection tools can see, not what exists. The true vulnerability rate of AI-generated code is substantially higher.
